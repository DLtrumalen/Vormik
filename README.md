# Vormik

Тренажёр эстонских падежей для русскоязычных. Приложение даёт слово и падеж, вы пишете правильную форму, а трудные формы повторяются чаще (интервальное повторение FSRS).

Проект состоит из двух частей:

- **Сайт** (`/`) — рассказывает о приложении и предлагает его установить.
- **Приложение** (`/train`) — сам тренажёр. Это PWA: его можно установить на телефон или компьютер, и оно работает без интернета. Прогресс хранится в браузере, регистрация не нужна.

## Стек

Next.js, TypeScript, Tailwind CSS, ts-fsrs, Vitest, ESLint, Prettier.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:3000. Service worker (офлайн-режим) включается только в продакшен-сборке: `npm run build && npm start`.

## Скрипты

| Команда                | Что делает                |
| ---------------------- | ------------------------- |
| `npm run dev`          | Сервер разработки         |
| `npm run build`        | Продакшен-сборка          |
| `npm start`            | Запуск продакшен-сборки   |
| `npm test`             | Тесты Vitest              |

| `npm run format`       | Форматирование Prettier   |
| `npm run format:check` | Проверка форматирования   |

## Словарь

Список слов с переводами лежит в `data/words.tsv`. Формы всех 14 падежей в обоих числах строит морфологический генератор [Vabamorf](https://github.com/Filosoft/vabamorf) (Filosoft, LGPL), результат сохраняется в `src/data/words.json`.

Чтобы добавить слова, допишите их в `data/words.tsv` и пересоберите словарь:

```bash
pip install estnltk
python scripts/generate_forms.py
```

## Структура

```
src/
  app/            страницы: сайт, тренажёр, манифест, иконки
  components/     кнопка установки, экраны тренажёра, блоки сайта
  lib/            падежи, проверка ответа, повторение, хранение прогресса

public/sw.js      service worker для офлайн-режима
scripts/          генерация словаря через Vabamorf
```
